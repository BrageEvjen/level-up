# Level Up website

The public website for Level Up, the quest and day-planning app. It is published with GitHub Pages from the `main` branch at https://brageevjen.github.io/level-up/.

Plain static files, no build step:

- `index.html` – the landing page (what the app does, price, questions, support)
- `terms.html` – terms, with refunds and cancellation under `#refunds`
- `privacy.html` – privacy policy
- `assets/` – stylesheet, fonts (Archivo and Figtree, SIL Open Font License) and screenshots

To change the price, the support address or any text, edit the HTML files and push to `main`. The site updates within a minute or two.
